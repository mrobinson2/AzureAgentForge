🔒
Operator gates — where you sign off
Human approval is required at each point below. The console enforces every one of these server-side, so they can't be skipped from the browser.
  • Subscription / billing gate
    You pick the Azure subscription in step 2. apply creates real, billable Azure resources — review docs/cost.md before you run it.
  • Secrets-in-Key-Vault gate
    Provider keys and the Postgres connection strings are seeded into Key Vault by you (scripts/bootstrap.sh, scripts/seed-keyvault.sh) — never typed into this browser UI.
  • Environment-name confirmation gate
    apply and destroy require typing the environment name (dev) before they run.
  • Destroy-approval gate
    If the saved plan would delete or replace any resource, a second, louder prompt requires typing approve-destroy. Pure adds and in-place updates apply without it.
  • CI/CD scaffold-apply gate
    Running the one-time CI/CD setup with apply mutates Azure identity/RBAC and GitHub config, so it requires typing scaffold-apply.
